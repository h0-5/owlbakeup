### قاعدة السكل المطبّقة: تباين نصوص 4.5:1 (قيم محسوبة فعليًا)

حُسبت بنسبة WCAG luminance، النتائج المُتحقق منها:

| التركيبة | التباين | الحكم |
|---|---|---|
| أبيض على `bg_default` (3,6,11) | **20.29:1** | ✅ ممتاز |
| أبيض على `primary` الحالي (94,76,252) | **5.36:1** | ✅ الثيم الحالي يمر |
| أبيض على تيل داكن (0,128,102) | **4.91:1** | ✅ البديل المقترح يمر |
| أبيض على وردي داكن (220,20,90) | **4.89:1** | ✅ CTA المقترح يمر |
| أبيض على تيل نيون (0,255,200) | **1.30:1** | ❌ للحدود والتوهج فقط — لا نص فوقه |
| `grey` الحالي (alpha 50) على الخلفية | **~1.58:1** | ❌ للنص الأساسي — ارفع alpha إلى 70+ |

**القاعدة العملية:** الألوان النيونة الساطعة تُستخدم كحدود/خطوط/توهج، والنصوص تُوضع
فوق النسخ الداكنة من نفس العائلة.

## 2) الخطوط (Typography)

الموجود فعلًا في `UIKit/fonts/` (دون تحميل أي ملف جديد):

| المفتاح | الاستخدام الموصى به (السكل: Chakra Petch mood) |
|---|---|
| `ui-default` (Font2 @ 11.5) | النص الأساسي في العناصر |
| `default-large` (Font2 @ 15) | العناوين الفرعية |
| `PFDin` (Regular @ 14) | النصوص العامة/الجداول |
| `PFDin-Bold` (@ 14) | أسماء اللاعبين، القيم المالية |
| `PFDin-Big` (@ 20) | عناوين النوافذ + الأرقام الكبيرة (HUD) |

**قواعد من السكل:**
- كل الأرقام المعروضة (فلوس/بنك/رواتب) تُنسّق بفواصل الآلاف: `1000000` → `1,000,000` —
  راجع قاعدة UX "Number Formatting" في السكل.
- نصوص عربية: أطوال الأسطر قصيرة، وتجنّب قطع الكلمة — استخدم `formatText` الموجودة أصلًا.

## 3) الإيقاعات (Spacing & Layout)

DX UI بلا flexbox — اعتمد مضاعفات شبكة 4px:

```
قيم مسموحة: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64
هوامش داخلية للنوافذ:      16 (هوية مكثفة) أو 24 (فضفاضة)
فاصل بين عناصر القوائم:     8
فاصل بين أقسام النافذة:     24
ارتفاع زر قياسي:           32 (مكثف) أو 40 (قياسي) أو 48 (CTA رئيسي)
ارتفاع صف gridlist:        28-32
```

## 4) الحركة (Motion) — 150-300ms

من توصيات السكل (انتقالات سلسة 300-400ms للـ 3D، 150-300ms للعناصر):

| الحالة | المدة | المنحنى (تقريب عبر interpolateBetween) |
|---|---|---|
| hover زر/صف | 150ms | ease-out |
| فتح/إغلاق نافذة | 250-300ms | ease-out |
| شريط تقدم/تحميل | 300ms خطي | linear |
| إشعار (notifications) | دخول 250ms / خروج 200ms | ease-out |

**إلزامي (قاعدة السكل):** احترم `prefers-receduced-motion` — بالألعاب: أوقف التحريك
إذا كانت جودة الرسوميات منخفضة (اقرأ `dxGetStatus("VideoCardLockdown")` أو إعدادات اللاعب).

- [ ] **تباين 4.5:1** — راجع جدول الألوان أعلاه
- [ ] **حالة focus/keyboard**: أي واجهة فيها حقول (بنك/شات) تدعم Enter = تأكيد و Esc = إلغاء

      العالم مرئيًا خلف النوافذ، أو أضف طبقة تعتيم dxDrawRectangle قبل النافذة

- [ ] **خطأ/نجاح/تحذير** بألوان `danger/success/warning` الثابتة — ولا تعتمد على اللون وحده:

## 6) التطبيق العملي — كيف تغير الثيم بالكامل

بما أن كل عناصر UIKit تستهلك `theme.COLORS`، تغيير الهوية البصرية = تعديل ملف واحد:

```lua
-- themes/theme_1.lua (مثال: هوية "نيون تيل" من السكل — قيم مُتحققة التباين)
theme = {
    COLORS = {
        primary      = tocolor(0, 128, 102),   -- تيل داكن (نص أبيض 4.91:1 ✅)
        secondary    = tocolor(0, 255, 200),   -- تيل نيون (حدود/توهج فقط)
        accent       = tocolor(220, 20, 90),   -- CTA وردي (نص أبيض 4.89:1 ✅)
        primary_dark = tocolor(0, 90, 72),     -- hover/active
        -- بقية القيم: راجع الجدول في DESIGN_SYSTEM.md
        ...
    },
    FONTS = { ... }  -- بدون تغيير
}
```

⚠️ **قبل أي تغيير:** تأكد أن الألوان الجديدة تمر فحص التباين (الجدول أعلاه).
⚠️ **لا تعد تسمية المفاتيح** — العناصر تعتمد عليها (token contract):
`primary, secondary, accent, primary_dark, black, bg_default, tabpanel_default{...},
scrollbar_default, text_default, grey, success, warning, danger`
